# Plans

Written implementation plans for multi-step work on Meowgoku.

## Workflow

The installed `superpowers` plugin has skills built around this directory:

1. `superpowers:brainstorming` — explore intent and requirements before design.
2. `superpowers:writing-plans` — turn the result into a written plan; save it here.
3. `superpowers:executing-plans` — work through a saved plan with review checkpoints.

Point the plan-writing step at this directory so the artifact lands somewhere
committed rather than in a scratch dir.

## Naming

`YYYY-MM-DD-short-description.md`, e.g. `2026-07-27-player-input-rework.md`.
Date-first keeps them ordered and makes staleness obvious at a glance.

## Lifecycle

Plans are working documents, not permanent records. Once the work ships, either
delete the plan or move whatever turned out to be worth keeping into
`../memories/` — the *why* usually outlives the *how*.
